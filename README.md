# Sales Data Analysis – Power BI

## Project Overview

This project analyzes sales data using Microsoft Power BI.
The dashboard provides insights into sales, profit, quantity sold,
discounts, orders, products, customers, promotions, and cities.

## Objectives

- Identify Top/Bottom 5 products by Sales, Profit and Quantity Sold
- Analyze sales trends over time
- Analyze the relationship between Sales and Profit
- Compare Sales, Profit and Quantity Sold between selected periods
- Analyze average discount by discount category
- Calculate total number of orders
- Analyze order-level details using filters
- Analyze sales across different cities

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel
